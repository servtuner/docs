## API conventions

The API speaks JSON. When served by the chart's ingress it is under `<basePath>/api`. Set `<base>` to the API's address and fetch the OpenAPI document from `<base>/openapi.json`.

Every request needs a signed-in user: a session from `POST /auth/login` (the `__Host-servtuner_session` cookie), or an identity named by a trusted proxy. The user's role decides which requests succeed; see [authentication](/deployment/authentication/). In `mtls` mode the listener also requires a client certificate. Posting run events requires the run's own token. With `auth.mode: none`, nothing is checked.
