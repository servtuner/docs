Run a three-stage benchmark against the mock server that ships with servtuner. You need no cluster, database, GPU or API key. The load takes three and a half minutes.

## Prerequisites

- Linux or macOS, on amd64 or arm64, with `curl`.
- A Go toolchain, for the mock server. Go downloads the version the mock needs.
- Port 18000 free.

## Get the CLI

Download servtuner from the [latest release](https://github.com/servtuner/servtuner/releases) and check it against the release's checksums.

<Tabs syncKey="os">
<TabItem label="Linux">

```sh
VERSION=<version> ARCH=amd64   # or arm64
mkdir -p /tmp/servtuner-quickstart && cd /tmp/servtuner-quickstart
base=https://github.com/servtuner/servtuner/releases/download/v$VERSION
curl -fsSLO "$base/servtuner_${VERSION}_linux_${ARCH}.tar.gz" -O "$base/checksums.txt"
sha256sum --check --ignore-missing checksums.txt
tar -xzf "servtuner_${VERSION}_linux_${ARCH}.tar.gz" servtuner
```

</TabItem>
<TabItem label="macOS">

```sh
VERSION=<version> ARCH=arm64   # or amd64
mkdir -p /tmp/servtuner-quickstart && cd /tmp/servtuner-quickstart
base=https://github.com/servtuner/servtuner/releases/download/v$VERSION
curl -fsSLO "$base/servtuner_${VERSION}_darwin_${ARCH}.tar.gz" -O "$base/checksums.txt"
shasum -a 256 --check --ignore-missing checksums.txt
tar -xzf "servtuner_${VERSION}_darwin_${ARCH}.tar.gz" servtuner
```

</TabItem>
<TabItem label="From source">

```sh
git clone https://github.com/servtuner/servtuner && cd servtuner
mkdir -p /tmp/servtuner-quickstart
(cd bench && go build -o /tmp/servtuner-quickstart/servtuner ./cmd/servtuner)
cd /tmp/servtuner-quickstart
```

</TabItem>
</Tabs>

`./servtuner --version` prints the version. To check the signature of `checksums.txt` too, see [verify downloads](/deployment/verify/).

## Run it

<Steps>

1. Save this RunSpec as `quickstart.yaml`.

   {/* schema: runspec */}

   ```yaml title="quickstart.yaml"
   apiVersion: servtuner.dev/v1
   kind: RunSpec
   name: quickstart
   target:
     type: openai-compatible
     endpoint: http://localhost:18000/v1
     model: mock-model
     tls: { mode: platform }
   engine: { type: loadgen }
   workload:
     api: chat
     streaming: true
     dataset:
       type: synthetic
       input_tokens: { mean: 128 }
       output_tokens: { mean: 32 }
   load:
     warmup: 30s
     stages:
       - { rate: 5, duration: 60s }
       - { rate: 10, duration: 60s }
       - { rate: 20, duration: 60s }
   slos: { ttft_p95: 500ms, e2e_p95: 2s }
   ```

   `platform` means plain HTTP. See [transport security](/deployment/transport-security/) before using it across a network.

2. Validate it.

   ```sh
   ./servtuner validate --spec quickstart.yaml
   ```

   ```text title="Output"
   ok: quickstart.yaml is a valid RunSpec (quickstart)
   ```

3. Start the mock in a second terminal.

   ```sh
   go run github.com/servtuner/servtuner/deploy/mocks/openai-mock@505d4f5b031c8dcabe5d59bb33e43f7fdbbd55a6 --tls-mode platform --listen 127.0.0.1:18000
   ```

   The first run downloads and builds the mock, which takes a minute. The commit is release 0.1.1's, so the mock matches this CLI.

4. Run the benchmark.

   ```sh
   ./servtuner run --spec quickstart.yaml --out ./quickstart-run
   ```

   The last line reports the run id, its result and the bundle directory.

</Steps>

## Verify

```sh
ls quickstart-run
```

The bundle contains `manifest.json`, `requests.parquet`, `analysis.json` and more. It is graded `degraded`, because no Prometheus was configured and the client's CPU had no limit to compare with. Its client-side numbers are still usable.
